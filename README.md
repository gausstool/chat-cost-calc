# 对话费用估算（chat-cost-calc）

基于 **Vite + Vue 3 + TypeScript** 构建的 **Agent 对话费用估算**工具。通过分层模拟真实 Agent 会话（会话 → 轮 → 步 → 工具调用）与逐次 LLM 调用的缓存模型，估算 Token 用量与费用。

## 功能特性

### 分层 Agent 模拟
真实 Agent 会话结构：每次**会话**含多轮**对话**，每轮含多个工具调用**步**（每次步都是一次实际 LLM 调用），每步可并行发起多个工具调用：

- **轮**：每会话对话轮数（默认 22）、每轮输入 Token、每轮正文输出 Token
- **步**：每轮工具调用步数（默认 7）、每步工具调用数（并行）
- **调用**：每工具调用输出（tool_use）与结果输入（tool_result）Token
- **思考**（reasoning）：每次 LLM 调用都产生，计输出费用；携带 tools 参数时按拼接规则进入上下文（DeepSeek 多轮拼接规则），否则不进入
- **系统提示词**：每轮请求携带的常驻前缀（可缓存），默认 3000 Token

### 缓存模型（逐调用模拟）
不使用解析公式，而是**逐步模拟每次 LLM 调用**累计命中 / 未命中输入：

- **命中缓存** = 请求中与上次请求相同的部分（固定前缀 + 历史上下文）
- **未命中缓存** = 本次新增（用户消息 / 工具结果回传）
- **缓存概率**（默认 99%）：每一步有 `1-p` 的概率缓存失效，前缀与历史整段按未命中计费（期望值口径）
- 思考按 DeepSeek 文档规则：携带 tools 时拼接进上下文并参与缓存前缀

### 预估消耗
实时输出：输入（命中缓存，含命中占比）、输入（未命中缓存）、输出（含工具调用）、总计，以及「实际上下文长度」（会话结束上下文总量，对照 1M 窗口占用）。

### 其他
- **支持缓存**开关、「**高峰时段**」（价格 ×2）开关
- 峰值场景快速切换：缓存命中率接近真实世界的 98%

## 默认值（参考真实会话校准）

| 参数 | 默认 |
|---|---|
| 每天会话次数 / 每会话对话轮数 | 1 / 22（≈170 步）|
| 系统提示词 Token / 每轮输入 Token | 3000 / 100 |
| 工具定义（数量 × 每工具 Token）| 10 × 100 |
| 工具调用（每轮步数 × 每步调用数）| 7 × 1 |
| 每工具调用（结果输入 × 调用输出）Token | 400 × 150 |
| 输出（每步思考 × 每轮正文）Token | 350 × 650 |
| 缓存概率 / 价格（命中 · 未命中 · 输出）| 0.99 / ￥0.05 · ￥1.5 · ￥4.5 |

校准结果：实际上下文长度 ≈ **170.5K（17% / 1M）**，缓存命中率 ≈ **98.6%**。

## 使用

```bash
pnpm install
pnpm run dev      # 启动于 http://localhost:1998
pnpm run build    # 构建到 dist
```

## 技术栈

- Vue 3（`<script setup>` + Composition API）
- Vite 6 + `@vitejs/plugin-vue`
- TypeScript
- UI 组件库：`@gausszhou/ui-vue-components` 与 `@gausszhou/ui-vue-theme-chalk`

## 目录结构

```
src/
├── App.vue                 # 根组件
├── main.ts                 # 应用入口
└── components/
    └── CostCalc.vue        # 费用估算的全部逻辑与界面
```
